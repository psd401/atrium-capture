# Mac app icon

- `AtriumCaptureIcon-1024.png` is the transparent 1024×1024 master.
- `AtriumCapture.icns` contains the standard macOS icon representations and is copied into the signed app bundle by `scripts/build-macos-app.sh`.

The original mark was generated on 2026-07-24 with OpenAI's built-in image-generation tool and no input image. It is an original capture-frame and reviewed-workflow symbol; it does not contain a production Atrium screenshot, frontend asset, third-party logo, font, or trademark. The generated chroma-key surround was removed locally, the master was normalized to 1024×1024 RGBA, and the `.icns` was derived from that master.

Generation brief:

> Create an original macOS icon for Atrium Capture using a deep-evergreen rounded-square field, a bold warm-ivory capture frame, and a simple mint three-step path ending in a privacy check. Keep the vector-like mark minimal, centered, text-free, high-contrast, and recognizable at 16 px. Use no borrowed logo, watermark, mockup, device frame, or production asset.
